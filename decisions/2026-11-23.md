# Decisions, 2026-11-23

One line per non-trivial choice: what was chosen and what decided it.

- **Modal is a backend of the existing training script (`--backend modal`), not a separate entry point.** Decided by: the instruction to use the Modal account for training, and the tier guard, which matches commands that launch the training script through a Python interpreter. A separate `modal run` entry point would bypass the tier check, the daily budget and the ledger; this way every remote launch passes through them and writes the same report, with the backend recorded in it.
- **The Modal image pins numpy, torch (CPU build) and gymnasium to the local versions, and adds `ocmdp/` and the training script from the working tree at launch.** Decided by: a report's git state has to describe the code that ran remotely.
- **Installed the Modal client (1.6.4) into `.venv` and declared it as the optional extra `modal` in `pyproject.toml`.** Decided by: the instruction to train on Modal. It is not a core dependency; local runs and the test suite do not need it (the backend test skips without it).
- **Smoke runs go to the scratch area, not `runs/`.** A 200-quarter run on Modal and the same run locally (two ledger lines today) agree to within 1.5e-7 on every field, float32 noise between x86-64 and arm64. They are plumbing checks, not results.
- **Training results reproduce across platforms only statistically, not seed for seed.** The full flat-target rerun on Modal (`runs/train/train_20261123_184321_12020.json`) matches the local report (`train_20261116_233400_32604.json`) exactly on every planner baseline, but every trained agent diverged: per-seed failure rates moved by up to 0.0055 and learning curves by up to 0.08. Consequences adopted: both agents of a pair always run on one backend (already enforced: one report, one backend); a seed's number is only comparable with runs on the same platform; each training record now carries the CPU and SIMD level it ran on (`host`). A second identical Modal run tests whether Modal reproduces itself.
- **Added a reference baseline to training reports: the oracle committed to its most probable drug per quarter** (`oracle[one drug per quarter]`). Decided by: the agents choose one drug per quarter, while the oracle may split a quarter between drugs, so the oracle may lie outside the agents' policy class and "share of oracle gain" may understate how close they get. It is a reference for the policy class, not an upper bound on it (the argmax of a mixed plan need not be the best one-drug-per-quarter schedule), and not a new comparator method.
- **Phase-diagram harness (`experiments/sweep_phase_diagram.py`), named so the tier guard and budget cover it.** Decided by: rank 4 in the order of work, needs no training, and survives either outcome of the entropy question. A two-cell dev pilot (`runs/phase/phase_20261123_184302_13496.json`) measured cost and spread: the every-quarter replanner costs about 6 s per episode, and the paired spread at sigma 0.2 needs about 80 episodes per cell for a half-width near 0.007. The full grid is held until the boundary is derived first, as the plan requires, so that measurement does not shape the prediction.
- **Superseding the hold above: the exploratory (delay, lam, sigma) map runs on dev now; the confirmatory test uses cells it never mapped.** Decided by: dev and test episodes of the same cells are exchangeable, so a prediction derived after a dev map and tested on test episodes of the same cells would not be a severe test either way. A severe test predicts the boundary at held-out instance parameters (other kappa, delta or horizon), fixed in a preregistration before those cells are run. Holding kappa, delta and horizon at their current values on dev keeps those axes clean.
- **The boundary is derived blind, by a separate agent barred from `runs/`, `decisions/`, the README's results and planner rollouts.** Decided by: the plan's derive-first rule, now that the dev map is running. The agent also predicts held-out cells (other kappa, delta, horizon) for the confirmatory test.
- **Phase-diagram figures are written as SVG by a standard-library script (`experiments/plot_phase_diagram.py`), output to `figures/`.** Decided by: matplotlib is not installed, and installing external code is reserved for the owner. Small multiples by memory, delay on x, one validated single-hue ramp for the ordered noise levels, sigma 0 in grey, 95% intervals on every point, predictions dashed; a CSV of every plotted value is written beside each figure.
- **Training summaries now carry the interquartile mean per agent and, for the pair, the probability of improvement, the number of seeds where OC-SAC fails less, a bootstrap interval of the mean paired difference over seeds and the IQM of the difference.** Decided by: the reporting rules require IQM or probability of improvement beside any mean over seeds, and the summaries had neither.
- **Modal containers do the same arithmetic: torch and MKL are pinned to their portable kernels (`ATEN_CPU_CAPABILITY=default`, `MKL_CBWR=COMPATIBLE`).** Decided by: two identical Modal runs (`train_20261123_184321_12020.json`, `train_20261123_184953_15052.json`) agree exactly on 9 of 10 training jobs and differ on one (OC-SAC seed 1), the signature of containers on CPUs with different SIMD kernels. The pinned environment is recorded in each report's `backend`, and every job's `host` records the dispatch level it ran at.
- **Acted on the first reviewer and validator reports, within proceed authority** (both reports came back today; their findings are summarised to the owner, not copied here). Changed in the training script: each agent's temperature path, dual-variable path and temperature quantiles at evaluation are logged; per-episode baseline values are stored, so agent-versus-baseline contrasts can be recomputed; the planner replanning every quarter is a baseline, and each agent carries paired-by-episode differences against every baseline instead of only oracle-normalised shares; `sac_config` is recorded per variant (it showed "pushforward" for both); `runs_beating_uniform` is renamed `runs_learned`, which is what it counts (more than half the oracle's gain over uniform); `git.dirty` covers code paths only and carries a hash of the code difference. The critic check is replaced: the old one could not fail, its correlation and `return_sd` being dominated by time-to-go. The new one tries each class for one quarter from every evaluation state on a copy of the environment, follows the agent's greedy policy, and reports whether the critic and the actor rank the classes as the environment does, and the regret when they do not.
- **Not changed, because each is reserved for the owner:** the entropy-target rule in CLAUDE.md (H = c log K for SAC is unreachable for c < 0.5 under the tied architecture, so SAC's temperature only falls; both agents confirm it); the rounded t table and the 1.96 fallback above 30 degrees of freedom in `ocmdp/eval/vv.py` (intervals over 40 episodes come out about 3% narrow); README numbers that rest on unlogged validation runs; the oracle docstring's "reproduces the rotation exactly" (off by about 3e-10); adding comparators; the response to the PRE-EMPTS hits.
- **The paired comparison also carries a two-level bootstrap interval (seeds, then episodes within each seed).** Decided by: both reviewers noted that intervals over seeds condition on the fixed evaluation episodes, so they say nothing about the episode population.
- **Every rollout in training and phase reports stores each drug's failure probability at the horizon.** Decided by: whether the reserve clause can fail depends on how resistant drugs end up, and no report kept it. Storing the raw values leaves the efficacy threshold, a metric definition reserved for the owner, unchosen.
- **Plan doc revised: a dated section at its top replaces the order of work (phase diagram and the exact-class result first) and lists the owner's open decisions.** Decided by: the instruction to revise the plan, and the reviewer's ranking.
- **The exploratory dev map is in: `runs/phase/phase_20261123_190013_15752.json`, 80 cells, 40 episodes each, on Modal.** Its numbers are kept from the blind derivation until that agent has delivered. Figures and CSVs for three contrasts are in `figures/`.
- **Figures recompute every mean and exact Student-t interval from the raw per-episode values in a report.** Decided by: the harness's interval at 39 degrees of freedom uses 1.96, so every stored half-width in the map is 3.2% too narrow (ratio measured on all 80 cells). The figure code does not depend on the locked harness; the harness fix itself is the owner's.
- **`experiments/predict_entropy_gap.py`: the exact-class entropy gap predicted from the mean-field model before it is measured.** For given temperatures it solves the class-entropy and drug-entropy soft-optimal schedules (drug entropy adds alpha * sum_j q_j log n_j under tied networks) and reports the difference in failure rate; with a training report it predicts at the temperatures the agents reached. Decided by: rank 1 of the revised plan; tested to give exactly zero gap with equal classes or zero temperature.
- **Theory-checker confirmed the identities on the implementation** (scratch scripts, not runs): under tied networks SAC equals OC-SAC plus a reward bonus alpha(s) log n_class(a); OC-SAC's entropy is KL-regularisation toward the class-balanced prior when no feasibility mask is used (under a mask the class sizes become per-state feasible counts); SAC's temperature can rise only if c > log n_min / log K, which on PairedDrugs is never for c <= 0.5. Training-length temperature dynamics were not checked; the reruns log them.
- **Analysis code for the rank-2 confirmatory test, written before any test-tier data exists:** `experiments/score_phase_predictions.py` (interpolated zero crossings, E = median |log(sigma_hat / sigma_pred)| with censoring oriented by one sign convention per contrast, a joint episode bootstrap, pass / fail / inconclusive against a margin, E minus E_null, direction checks between settings) and `experiments/null_phase_predictions.py` (the theory-free competitor: dev-map crossings carried unchanged to held-out settings). Decided by: the reviewer's draft preregistration. The margin, cells and rules in it are a draft for the owner to freeze or change; the code takes them as arguments. A synthetic test found and fixed a crossing missed when a mean is exactly zero at a grid point.
- **The phase sweep takes `--kappa` and `--delta`, and gains the contrasts `greedy_regret` and `planned_once_minus_greedy`.** The second is the one whose sign can fail in both directions, which a confirmatory test needs; the earlier contrasts are non-negative by construction under noise. The training script takes `--delay` and `--lam` for agents at chosen phase cells. Defaults reproduce the earlier configurations.
- **The blind derivation agent was asked to predict the reviewer's held-out settings and the new contrast as well, with no measurements attached.**
- **Reruns with temperatures logged, pinned Modal, dev seeds 0-4, sigma 0:** flat target `runs/train/train_20261123_190717_20498.json`, zero target `runs/train/train_20261123_190750_20538.json`. They are diagnostics, not results. In both, SAC's temperature sits at the clamp floor at every evaluation state; OC-SAC's median evaluation temperature is at the floor too, while its training-window mean stays high on some seeds. With the zero target both agents optimise the same objective, so their paired difference measures the seed-chaos floor between two agents that differ only in seed; its five-seed bootstrap interval excludes zero while its t-interval does not, which is why the t-interval stays primary at five seeds.
- **The counterfactual critic check runs without noise only.** Decided by: with noise each counterfactual follows one noise path, so its ranking error cannot be separated from the critic's (reviewer, round 2). The check also measures only consistency with the agent's own continuation.
- **Gap attribution against the planner, opt-in (`--diagnose-gap`, no noise only).** At every evaluation decision the planner's value from that state and from each class for one quarter then the planner; the per-decision losses telescope to the agent's gap to the planner (checked, `closure_error`) and split into the policy-class cost, the agent's own continuation ranking classes differently from the planner, critic misranking, and the actor departing from its critic. Decided by: the reviewer's round-2 point that self-consistency cannot separate the plan's causes 2 and 3. Running now on the flat target.
- **Correction to an entry above:** the two unpinned Modal runs (`train_20261123_184321_12020.json`, `train_20261123_184953_15052.json`) do not "agree exactly on 9 of 10 jobs". Per the validator: 4 jobs are bit-identical, 5 are identical in every training field and differ by up to 1.7e-15 in fields numpy computes (so container arithmetic differs outside torch too), and 1 (OC-SAC seed 1) diverged. The pinning comment in `modal_backend.py` now says numpy's dispatch is not pinned. The `--diagnose-gap` run trains the same configuration as `train_20261123_190717_20498.json` with the pinned image, so its training fields test whether pinned Modal reproduces itself.

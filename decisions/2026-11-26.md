## Code standards pass: fixes on branch code-standards (uncommitted worktree)

- **Where:** a git worktree on branch `code-standards` from 4788c5a, under the session scratchpad. The main tree keeps the code that ran step 1, so step 2 can launch from 4788c5a.
- **What decided it:**
  - Two NeurIPS-standards reviews: one of the repository, one of the first diff.
  - A statistics verifier, which recomputed the step-1 verdict independently and agreed with it.
  - A run audit of the README.
- **Chosen:**
  - **Per-agent temperatures.** `--set-oc-sac` and `--set-sac` may carry only `temperature`, `alpha` and `target_fraction`, the CLAUDE.md candidate set. `alpha_init` is refused because it also sets `alpha_lr`.
  - **Diverged runs count everywhere.** A diverged run is imputed at max(uniform, the worst completed run of either agent at that noise level) in every failure-rate statistic: mean, IQM, gain shares, runs_learned and the paired difference.
    - Pooling over both agents makes a seed where both diverged give a difference of 0.
    - With U − R > 0 the rule equals check_dev_protocol's g = min(0, the lowest g).
    - A variant with every run diverged is not summarised: exit 1, a stop.
  - **Gain-share guards.** The replanner must fail less than uniform, or the noise level is not summarised. The oracle must as well, but only at σ = 0; under noise an oracle that does not beat uniform gives no noise-free-planner share.
  - **Floor check.** It fails below −1e-4 of the entropy range.
  - **Step 2 needs one code state.** Every report must share one commit and code diff, so step-2 runs and step-1 runs at L* ran the same code.
  - **Report schema 4.** It marks the new summary rule. The step rules accept schemas 3 and 4, because they recompute from the runs, which are unchanged.
  - **`entropy_objectives_coincide`** is set for c-given, equal class sizes and equal temperature settings. The wording is "tie expected". Identical training is guaranteed only at fixed temperature 0, because the critic targets differ by alpha · gamma · log n.
- **Not changed, for the owner:**
  - The minimum denominator U − R, a threshold to fix in advance.
  - The primary metric for "at equal treatment cost". The efficacy threshold sits in ocmdp/eval/, which is protected.
  - The no-c confound: OC-SAC's entropy still uses C's classes.
  - Whether (2, 2) belongs in step 2.
  - The licence.
- **No training computation changes.** With `--set-oc-sac` and `--set-sac` empty, each agent's configuration equals the earlier shared one, and the job tuple keeps its shape. experiments/train_agent.py is in VAL_CODE_PATHS, so a val selection and its test run must both use the new commit or both the old one.
- **Revised after the re-review of the branch (this supersedes two lines above):**
  - **Imputation.** In an agent's own statistics a diverged run takes max(uniform, that agent's own worst completed run). This keeps each agent's tuning score independent of the other agent's runs. The pooled worst, over both agents, is used only in the paired comparison.
  - **Step-2 code check.** It compares the content of VAL_CODE_PATHS at each report's commit (`git rev-parse <commit>:<path>`), not commit ids. A commit that adds only run reports passes; a dirty or unknown commit fails.

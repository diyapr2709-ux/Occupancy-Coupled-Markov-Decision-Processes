# Outcome: rung 1, reproduction

Judged blind against `2026-11-23-reproduction-criteria.md`. Ranking: proposal 3 first, proposal 2 a close second, proposal 1 third. Adopted: proposal 3, amended as the judge required, with the elements the judge named from proposals 1 and 2. Criterion 4 (cost) did not discriminate.

## Adopted decision

- **Target:** Weaver et al., PNAS 2024 (DOI 10.1073/pnas.2303165121), base case on the Mira et al. 2015 landscapes (15 drugs, 16 genotypes, start at genotype 0, 20-step episodes, 500 training episodes).
- **Route:** a reimplementation in this repository under `experiments/repro/weaver2024/`, specified from the paper, the SI and a read-only reading of the authors' code at commit 16335ce (`evo_dm`, GPL-3.0) and of `rl_cycling` at d68cf07 (no licence, read only). No code text is copied. A spec file fixes one reading per unstated detail with its source, in the order of precedence: published text, SI, `evo_dm` at 16335ce, `rl_cycling` at d68cf07. Landscapes are transcribed twice, independently, from Mira 2015 Table 4 (CC BY) and diffed against the code's list form; the runs use the values on the code path the authors' harness executes, and every disagreement is reported.
- **Read-only look before the preregistration is frozen** settles, as facts: effective hyperparameters and `train_freq`; the done flag; normalisation and the landscape scale of each comparison (a two-drug comparison mixing scales is a stop); the noise definition (pinned here, paper against code); which form of ZOX runs; how two-drug cycles are enumerated and estimated; the base case's sensor noise as the harness ran it; how "measurable decrease" (SI Fig. S1A) and the edge weights are computed in the figure code; the episode counts behind 1.88 and 1.41. The unfinished application literature search is completed in the same step, and a target with numeric tables and pinned code reopens this decision.
- **Gate 0, environment (exact, no learner):** E1 landscape audit (reported, not gating); E2 the MDP uses cefotaxime in more than half of the steps; E3 exact random-cycling expectation against 1.88 with band 0.005 + 3 sigma_ep / sqrt(n), n the smallest episode count in the authors' harness (100) unless the look identifies the count; if the origin or scale of 1.88 cannot be identified, E3 drops out, recorded before any run. Any failure: report and stop.
- **Gate 1, learners, dev seeds 0-99:** L1 RL-genotype beats random and every two-drug cycle (authors' comparison procedure, exact expectations as fallback), two-sided Fisher exact test against 100/100; L2 RL-fit's "measurable decrease" against random (authors' definition, Welch fallback), Fisher against 98/100; L3 RL-fit at noise modifier 40, equivalence: the 95% interval of the 100-replicate mean lies inside 1.41 +/- 0.10. Correlations 0.96 and 0.82 gate only if the authors' edge-weight construction is unambiguous. Exact Fisher cut-offs computed by script before freezing.
- **Discrimination checks, preregistered:** an untrained network acting greedily and a DQN trained on reward shuffled across time steps must both fail L1 and L2; a myopic-greedy rule is reported as a diagnostic. If a control passes, the gate is declared non-discriminating.
- **If it does not reproduce:** report each quantity with ours, theirs, the tolerance and the interval, and stop. Any later change is post hoc and never presented as the reproduction. The authors' code runs only with the owner's approval, after a review of all its source, in an offline container fetched by commit hash, with outputs brought into `runs/` with file hashes.
- **Rungs 2 and 3:** a candidate drug-to-class map from the WHO ATC index (checked against the index, not recalled), with the caveat that all 15 drugs act against one TEM beta-lactamase, so classes are a proxy; the coupling-zero bridge test; at rung 3 the unchanged published DQN beside a strongest-honest DQN, the latter labelled as such.

# Outcome: the temperature protocol

Judged blind against `2026-11-23-temperature-criteria.md`. Ranking: proposal 3 first, proposal 2 a close second, proposal 1 third. Proposal 3's lead was conditional on removing the state-dependent temperature alpha(s), an owner decision; under the owner's instruction to resolve such decisions by arena, it is taken (the logs already show alpha(s) pinned at the clamp floor at evaluation for both agents). Adopted: proposal 3 with the amendments the judge required.

## Adopted decision

- **Temperature is a per-agent hyperparameter chosen at parity, never one constant scaled per agent.** Every entropy-regularised agent is tuned over the same candidate set, on the same val seeds, cells and evaluation episodes, with the same number of runs:
  - fixed temperatures {0, 0.01, 0.03, 0.1, 0.3, 1, 3}, in scaled reward per nat;
  - learned scalar temperatures with target H_floor + c (H_max - H_floor), c in {0.77, 0.89}, where H_floor and H_max are the least and greatest entropy the agent's own policy class can reach in its own entropy space (computed from the actions its networks cannot tell apart; under tied drugs SAC's floor is log n_min). 0.98 is left out (unstable beyond 100k steps per CleanRL).
- **The learned temperature's loss is taken on the raw scalar with a reflecting mask:** no gradient pushes it further outside the clamp range, and a gradient pushes it back in.
- **alpha(s) is removed:** the policy head's temperature head and the rising entropy target go; a scalar temperature replaces them. OC-SAC's design changes accordingly.
- **Fixed-grid widening, entropy only, on dev:** if at the largest fixed temperature either agent's mean class entropy at evaluation is below 0.9 log M, append half-decade points; if at 0.01 either is above 0.1 log M, prepend them; identically for every agent. A learned fraction selected at a grid edge triggers a new dated decision before any test run.
- **Selection:** the primary metric is fixed in the preregistration before the val grid runs. Each agent takes the candidate with the best interquartile mean of that metric over 10 val seeds and every preregistered cell; ties go to the earlier candidate (fixed ascending, then learned ascending). The full table and both choices are frozen in the preregistration; the matched-temperature curve is reported beside the tuned comparison.
- **Dev check before val:** candidates {fixed 0, 0.1, 3; learned 0.89}, both agents, dev seeds 0-4, sigma 0, class sizes (2, 2) and (8, 5, 4, 2, 1). It applies the widening rule; checks that a learned temperature stays off the clamp in every window and at evaluation, with |H - target| / (H_max - H_floor) below 0.1 in the last window; compares the computed floor with the lowest entropy reached (a gap above 10% of the range means the floor is wrong, the near-tie case); and checks that at matched fixed alpha on (2, 2) the paired difference sits within the seed-chaos floor.
- **Named differences between the agents:** the tuned temperatures may differ; the reachable ranges differ; with unequal classes SAC's extra term alpha log n_class(a) favours large classes; with partial overlap SAC can earn entropy between near-identical drugs; the learned temperatures each agent reaches differ.
